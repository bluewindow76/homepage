# 官方公开资料摘录：支出标准体系建设实施方案报道

**资料类型：官方新闻报道摘录；不是制度原文。**

- 发布机关：福建省财政厅
- 发布日期：2025-06-23
- 原文链接：https://czt.fujian.gov.cn/zwgk/czxw/202506/t20250623_6930400.htm

## 摘录摘要

福建省财政厅报道确认已印发《福建省省级支出标准体系建设实施方案》。报道说明，方案通过规范支出标准制定、加快标准体系建设、健全标准应用机制推进财政支出标准化。

报道指出，标准制定需反映合理需求和财力状况，充分利用预算评审、决算、绩效管理等信息；支出标准将作为预算编报、审核和安排依据。适用标准的项目应在标准限额内编制预算；同时适用综合标准和分项标准的项目，实行分项核定、总额控制。福建省还计划建立支出标准库，将标准嵌入预算编审流程，并按“谁制定、谁调整”原则建立动态调整机制。
