## 建议的后续官方获取路径

1. 在福建省财政厅网站“政策文件”栏目按完整标题、关键词分别检索。
2. 联系福建省财政厅预算处/预算编审中心，询问可公开版本、发文文号及配套附件。
3. 如未公开，按政府信息公开渠道申请获取；若属于预算管理一体化系统内部工作材料，应由有权限的业务渠道确认能否提供。
