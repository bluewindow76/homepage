# 官方公开资料摘录：福建省纵深推进零基预算改革纪实

**资料类型：官方新闻报道摘录；不是制度原文。**

- 发布机关：福建省财政厅
- 发布日期：2026-09-18
- 原文链接：https://czt.fujian.gov.cn/zwgk/czxw/202609/t20260918_7215048.htm

## 摘录摘要

报道介绍福建省零基预算改革中的项目退出与整合、支出标准体系、预算评审、资金统筹、绩效管理和数字化监管实践。

与预算智能评审直接相关的公开信息包括：
- 将人员经费、公用经费和不同类型项目支出分类管理，分别采用统一标准、综合定额、工作量据实测算或政策标准与受益对象测算等方法。
- 对政策到期、目标相近或存在交叉的专项资金开展退出或整合评估。
- 将《省级预算评审管理实施细则（试行）》和《关于规范项目支出预算评审流转程序的通知》列为已出台制度。
- 报道提及使用“编制规定+工作量匹配+标准复算”的评审方法分析预算需求，并介绍了预算评审试点和智慧财审系统建设。
- 推进项目库全生命周期管理、部门存量资金统筹、绩效评价和财会监督数字化。
