# 官方公开资料摘录：预算评审实施细则解读

**资料类型：官方新闻/政策解读；不是制度原文。**

- 发布机关：福建省财政厅
- 发布日期：2025-06-26
- 原文链接：https://czt.fujian.gov.cn/ztzl/sxzy/202506/t20250626_6935420.htm

## 摘录摘要

福建省财政厅报道《福建省省级预算评审管理实施细则（试行）》于2025年6月18日起施行。报道说明，细则明确项目主管部门承担预算评审主体责任，要求做好审核把关并实现评审闭环管理。

官方解读称，评审范围实行应评与免评，重点关注党委政府重点项目、巡视审计和绩效管理中发现问题较多的项目，以及若干特定类别和金额规模的项目。评审内容包括项目立项必要性、可行性、完整性，预算合规性、合理性、经济性，以及绩效目标、支出标准。延续性项目还需关注以前年度预算执行与绩效管理情况。
