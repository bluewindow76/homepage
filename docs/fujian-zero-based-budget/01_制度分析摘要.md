# 福建省零基预算改革与预算评审制度摘要

整理日期：2026-10-10

## 1. 核心判断

福建省零基预算改革不是简单“砍预算”，而是将预算资源配置从历史基数惯性转向以政策依据、实际任务、支出标准、项目必要性、绩效表现和财政承受能力为基础的重新论证。支出标准负责形成日常测算的“标尺”，预算评审负责对重点、高风险、复杂或缺少标准的事项开展深入核验，项目库连接项目储备、预算编制、执行和退出，绩效评价则将资金使用结果反馈至后续预算安排。

## 2. 主文披露的改革机制

### 2.1 从基数依赖转向从零审核

- 基本支出区分人员经费、公用经费；人员经费按统一工资津补贴等标准编制，不得以公用经费或项目支出弥补人员经费。
- 公用经费执行综合定额标准，从严从紧编制。
- 项目支出细分为基本业务费、专项业务费、补贴清算类、发展性支出等类型，并采用差异化测算方式。
- 政策到期的专项资金原则上退出；政策期限未明确但超过3年的，按报道所述改革口径视同到期（须结合适用政策及例外条款核验）。
- 新增专项资金须开展事前评估，评估结果作为预算申请必备要件。
- 对目标相近、投向交叉的专项资金开展整合，避免重复安排。

### 2.2 建立支出标准体系

- 标准制定、发布、应用、调整、评估纳入制度化管理。
- 以基本支出、项目支出为主搭建标准框架，并区分财政标准与部门内部标准。
- 标准制定依据涵盖法律法规、政策部署、市场价格、历史数据等多类依据。
- 建立动态更新机制，遵循“谁制定、谁调整”，结合经济社会发展、财力变化、政策变化和实际应用情况复审标准。
- 支出标准数据库与预算管理一体化系统结合，推动标准库、项目库、资金库关联；以基础数据自动测算预算。
- 2026年9月主文披露：截至2026年7月，标准库累计433项，其中基本支出标准82项、项目支出标准351项。其他不同日期的报道披露过442项等数据，属于不同统计时点或口径，引用时应注明来源日期，不能直接视为矛盾或混用。

### 2.3 重点项目预算评审

官方解读明确，预算评审围绕“谁来评、评什么、如何评、怎么用”规范全过程：
- 项目主管部门承担预算评审主体责任，对由主管部门负责评审的项目把关并形成闭环。
- 实行应评与免评，集中评审资源。
- 重点关注省委、省政府重点项目、巡视审计绩效管理中发现问题较多的项目，以及达到特定金额门槛的项目。
- 官方解读披露的门槛包括：特定目标类项目资金需求1亿元以上、专项业务费2000万元以上、专业性强或技术复杂项目400万元以上、基本建设项目3000万元以上。
- 人员类项目、公用经费项目、按规定标准可直接测算资金需求等8类项目在解读中被列为免评类型。完整免评范围必须以实施细则原文为准。
- 评审内容包括立项必要性、可行性、完整性，预算合规性、合理性、经济性，绩效目标和支出标准；延续性项目还要审查以前年度预算执行和绩效管理情况。
- 对虚报基础数据或资金需求的，酌情核减预算；评审结果作为预算安排的重要参考。

### 2.4 以“编制规定 + 工作量匹配 + 标准复算”核验预算

主文案例：某特种设备检验检测项目申报运行成本性支出预算4.5亿元。由于国家相关检验检测规则调整、业务量明显下降，但人员支出预算未同步变化，财政部门逐项核算后审减9800万元。

由此可提炼出一个高价值评审路径：
1. 核对最新法律政策、业务职责和编制规定；
2. 核对当年真实工作量及政策变化；
3. 将工作量映射到人员、服务、设备、耗材等成本驱动因素；
4. 按适用支出标准重新测算；
5. 比较申报数与复算数，定位差异原因；
6. 形成逐项证据和可解释的审减建议。

该案例说明：历史预算数不能自动成为本年合理预算数，业务量变化应传导到成本和预算需求。

### 2.5 项目库、资金统筹和绩效反馈

- 项目从前期谋划、项目储备、预算编制、项目实施到结束/终止，相关阶段信息动态入库。
- 统筹部门存量资金、非财政拨款收入、中央与省级同领域资金，减少重复安排。
- 对执行进度慢、效果不佳或当年无法实施的项目，按程序核减预算或收回统筹；连续两年未用完资金的处理需遵循适用规定及例外。
- 专项资金事中绩效评价与预算压减、奖励及后续资金安排联动。
- 预算安排应兼顾重点保障、民生底线和财政可持续性，不宜把“审减率越高”作为唯一目标。

## 4. 对智能评审系统的启示

1. **规则优先级**：法律法规和有效政策 > 正式支出标准/编制规定 > 项目批复和业务任务依据 > 历史数据与经验参数。历史执行数只作为证据，不是默认预算基数。
2. **先分流、再评审**：先判断适用规则、评审范围和免评条件；命中应评条件的进入深度评审，免评也应保留依据与审批记录。
3. **标准复算与合理性判断分离**：机器可复算金额，但必要性、政策优先级、技术方案和特殊情况可能需要专业人员判断。
4. **证据链必须完整**：每条规则输出数据来源、政策版本、计算公式、输入值、计算结果、差异解释和人工确认状态。
5. **避免机械审减**：异常只触发核查，不等同于违规；差异应区分政策变化、工作量变化、价格变化、结构变化、数据质量问题及合理特殊事项。
6. **闭环反馈**：评审意见、部门反馈、最终审定金额、执行结果和绩效结果应回流项目库与规则评估流程，支持标准更新和规则质量监测。
